Scope

What we build

An installable Progressive Web App for your guards, a planning console for your bureau, and the deployment + handover that goes with it. Fixed price, fixed scope.

Employee app
PWA · mobile-first
  • Installable on the home screen (iOS & Android)
  • View shifts and shift details
  • Accept or decline assigned shifts
  • Set weekly availability
  • Push notifications for new assignments and changes
  • In-app chat with the planner
Admin console
Planner · web
  • Create and assign missions
  • Global week planning view (employees × shifts)
  • Employee management — create & edit profiles
  • Automatic CAO hours-cap check on assignment
  • In-app chat with employees
  • Activity and coverage overview
Delivery & handover

Production-ready. Full handover.

We deploy to a dedicated production environment, hand over the source code, and provide a concise technical manual for maintenance and future iterations.

  • Production deployment on werkkompasbv.nl
  • Source-code handover (private GitHub repo)
  • Concise technical documentation (setup, deploy, maintenance)
  • Configuration and deploy runbook
